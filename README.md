# BAZARCIK_PM — Discord-бот

Экономика, работа (склад GymBeam и McDonald's), мини-игры (казино и «Дурак»), бизнесы, кредиты, ИИ-ассистент
и инструменты модерации. Префикс команд — `!`, полный список — `!help`, админам — `!adminhelp`.

## Запуск

Нужен Python 3.10–3.14 и FFmpeg (для голоса).

```bash
pip install -r requirements.txt
python main.py
```

На хостинге запуск задан в `Procfile`: `worker: python main.py`.

## Переменные окружения (`.env` или настройки хостинга)

| Переменная | Обязательна | Что это |
|---|---|---|
| `DISCORD_BOT_TOKEN` | да | Токен бота |
| `GROQ_API_KEYS` | для ИИ | Ключи Groq через запятую (старое имя `GROQ_API_KEY` тоже работает) |
| `GROQ_MODEL` | нет | Модель Groq; по умолчанию `openai/gpt-oss-120b`, при отключении модели бот сам перейдёт на следующую |
| `AI_SYSTEM_PROMPT` | нет | Характер ИИ. Встроенный (`config.py`) — BazarčikPM Bot: зеркалит тон, защищает Юру, знает команды бота. Переменная полностью его заменяет |
| `TTS_VOICE` | нет | Голос озвучки, по умолчанию `ru-RU-SvetlanaNeural` |
| `LOCAL_WAKE` | нет | `0` — выключить локальный детектор «Базарчик» (тогда каждую фразу из войса распознаёт Whisper) |
| `WAKE_MODE` | нет | `rivals` (по умолчанию) — детектор со словами-соперниками, меньше ложных срабатываний; `classic` — прежняя облегчённая версия |
| `SPT_STATUS_GIST_ID` | нет | Gist со статусом SPT-сервера (старая `SPT_STATUS_GIST_URL` тоже понимается) |
| `SPT_STATUS_GIST_FILENAME`, `SPT_STATUS_GITHUB_TOKEN` | нет | Имя файла в gist и токен для частых проверок |

## Голосовой ассистент («Джарвис»)

В чате к боту обращаются **только упоминанием**: `@BazarčikPM сколько у меня денег`,
`@BazarčikPM зайди к нам в войс`. Бот сам решает: выполнить команду или ответить на вопрос как ИИ.
Если бота упомянули, но говорят о нём, а не ему («вот наш @BazarčikPM теперь такое умеет»), он ставит
реакцию вместо ответа — по смыслу (😎 🙄 😂 🫡 ❤️ 🤖 👀) или свою: `!упоминания реакция 🔥`; `!упоминания игнор` — молчит совсем, `!упоминания ответ` — отвечает как раньше
(настройка сервера, меняют администраторы).
Команды `!ask` больше нет.

**Прозвища** (`!alias`, `cogs/aliases.py` + `names.py`, хранятся в `user_aliases.json` по ID участника):
по ним бот понимает, о ком речь — «@BazarčikPM замуть Петруху». Администраторы меняют прозвища любого
участника сразу; остальные — только свои и только с одобрения администратора (бот присылает запрос с кнопками).
Свои прозвища смотрит любой (`!alias`), чужие и весь список (`!alias @user`, `!alias list`) — администраторы.
Всё это можно и словами: «@BazarčikPM запомни, что Петруха — это Петя», «какие у меня прозвища».
У одного человека может быть до 15 прозвищ, добавлять и убирать можно по несколько сразу: `!alias add @Петя
Петруха, Петюня и Петро` (через запятую, «и», «a», «and»; целиком в кавычках — одно прозвище) или «зови Петю
Петруха и Петюня». Обычный участник получает один запрос на все свои прозвища.

Людей бот ищет между языками: словацкое «č» = «ч», украинские «и» и «г» в латинице — «y» и «h», «й»/«j»/«ы» —
одно и то же, двойные буквы не важны. Поэтому «Миколу» найдёт Mykola, «Олега» — Oleh, «Шимона» — Šimon.
Это только поиск; прозвища в файле сравниваются по-прежнему (`norm_name`), чтобы проверка при запуске ничего
не удалила.

Как хранятся — образец с правилами в `user_aliases.example.json`:

```json
{
  "_как_заполнять": ["ключи на «_» — комментарии"],
  "ID сервера": {
    "ID участника": ["Петя", "Петруха"],
    "ID другого участника": ["Юрчик"]
  }
}
```

ID — цифры в кавычках (режим разработчика в Discord → ПКМ → «Копировать ID»), прозвища — всегда списком,
2–32 символа, одно прозвище — у одного человека на сервере; регистр, алфавит и падеж не важны. Править файл
руками — только при выключенном боте. При запуске бот проверяет файл: ошибки исправляет или убирает и пишет
в лог `[alias]`, что именно. Сам `user_aliases.json` в git не попадает.

`!listen` — бот слушает войс и отвечает на фразы, которые начинаются с «Базарчик, …»; запасной путь —
голосовое сообщение «Базарчик, …» в чате. Если в фразе просьба что-то сделать, бот сам выполняет свою
команду от имени говорящего, коротко говорит итог голосом и дублирует его в чат:
«Базарчик, сколько у меня денег» → `!money`, «Базарчик, замуть Петю на 10 минут» → `!mute`.
Просто вопрос — обычный ответ ИИ. Список голосовых действий — `!jarvis`.

Бот слушает один язык сервера — русский (по умолчанию), украинский, словацкий или английский: Whisper получает
язык сам и не угадывает его, поэтому фраза распознаётся одним запросом. `!язык` — какой сейчас, `!язык sk` —
сменить (администраторы); голосом — «Базарчик, слушай нас на словацком». Действует на войс и голосовые сообщения,
на этом же языке бот отвечает на просьбы голосом. Хранится в `guild_config.json` (`listen_lang`).

В войсе бот разговаривает с одним человеком за раз. «Базарчик» без вопроса — бот отвечает «Слушаю, <имя>» (первое
прозвище, иначе ник без значков; на языке прослушки) и 10 секунд ждёт вопрос от этого человека без «Базарчик».
Пока разговор не закончен — бот распознаёт фразу, ждёт вопрос, отвечает или ждёт подтверждения кика/бана, — фразы
остальных пропускаются ещё до детектора (в логе — «бот разговаривает с …», в сводке — «пока занят другим»).
Окно для вопроса отсчитывается от конца «Слушаю», а фраза засчитывается, если началась в окне.
«Базарчик, сколько у меня денег» одной фразой работает как раньше.

Пока бот читает ответ, он не слушает никого — даже собеседника, кроме «Базарчик, стоп» («хватит», «замолчи»…)
от него: озвучка обрывается вместе со всем, что ждало очереди, бот говорит «Хорошо» и снова слушает всех.
Вопрос-подтверждение (кик, бан, перевод) «стоп» не прерывает — его бот договаривает целиком, а ответить «нет» можно
после. Голосом бот читает одно-два предложения ответа ИИ (до 130 символов, ~10 секунд) и добавляет «Остальное — в чате».
Короткая неразборчивая фраза в окне вопроса (уверенность Whisper ниже −1) вопросом не считается — окно ждёт дальше;
«да» на подтверждение это не касается.

Кого ИИ выбрал для просьбы («забань подкидыша»), должен быть назван во фразе — ником, его частью, прозвищем
(с падежом и транслитом), @упоминанием или словом, которое ИИ и взял из фразы. Иначе бот не выполняет команду, а
переспрашивает «назови по имени»; в отказах (иерархия ролей) называет, о ком речь.

После `!listen` бот пишет, когда реально готов слушать: сразу «🎙️ Слушаю войс — можно говорить» или «Захожу в войс — секунду…», а потом «✅ Готов слушать» (ждёт ключи шифрования голоса Discord и загрузку детектора).

«@BazarčikPM чему новому ты научился» (или `!чтонового`) — бот рассказывает, что добавили с прошлого раза:
«За ночь мы с алкашом добавили такие приколюхи», а дальше каждое изменение — отдельным сообщением, по порядку
по 5 за раз (`MAX_ITEMS` в `whatsnew.py`; остальное — на следующий вопрос): заголовок и описание коммита git
(на хостинге без git — разделы `CHANGES.md`); откуда прочитано,
бот пишет внизу последнего. О чём уже рассказано, запоминается для каждого
сервера; `!чтонового все` — свежее заново.

После крупного обновления вместо списка коммитов — подборка из `whatsnew_release.md`: по одному сообщению
на вопрос, дальше — кнопка «▶ Далее», `!чтонового далее` или «@BazarčikPM что ещё нового». Каждый сервер
видит её один раз; досмотрели — коммиты обновления считаются рассказанными. Новая подборка — новый `id` в
файле, `!чтонового подборка` — показать заново.

- Голосом выполняется только белый список (`ACTIONS` в `cogs/jarvis.py`), права проверяются так же,
  как у текстовой команды.
- Мут, варн, медленный режим, замок чата — сразу. Кик, бан, очистка чата — строгое подтверждение: бот
  договаривает вопрос, создаёт форму в чате и 30 секунд ждёт полную фразу вроде «подтверждаю, забань Petya»
  (или кнопку). Переводы и крупные ставки — после «да» (15 секунд).
- Команды модерации понимают ник, прозвище, падеж и транслит: `!mute Петруха 10m`, `!clear от Петрухи за 2ч`.
- `!reload`, `!backup`, `!botstatus` и настройки сервера голосом не выполняются никогда.
- Звук живёт только в памяти до распознавания, фразы без обращения к боту не сохраняются.
- Обращение «Базарчик» в войсе сначала слышит офлайн-детектор прямо на сервере бота (`wake_word.py`, Vosk),
  и в Groq Whisper уходят только фразы с обращением. Модель (~45 МБ) скачивается сама при первом
  `!listen`, на диске занимает ~56 МиБ, в памяти ~90 МиБ — и только пока бот слушает войс.
  Похожие фразы («базилик», «за базар чиста») отсекают слова-соперники; прежняя версия — `WAKE_MODE=classic`.
  Обращением считается и то, как модель слышит «Базарчик» с другим произношением: «базар/базары/базара/база»
  + «чик/чика/чику/чек/чирик» в начале фразы, не дальше секунды друг от друга.
- Распознаёт фразы `whisper-large-v3` (Groq), запасная — `whisper-large-v3-turbo`. В подсказку Whisper бот
  кладёт имена людей в войсе и прозвища сервера (до 200 символов) — так имена реже превращаются в созвучные слова.

## Режимы ответа ИИ

У каждого участника свой режим — как бот ему отвечает (`!режим`, `reply_modes.py`, хранится в `reply_modes.json`):
- 🗣️ **Стандартный** — как раньше: на языке собеседника (русский, украинский, словацкий, английский);
- 🔤 **Язык админов** — транслит латиницей: «Privet, tipo vot tak budu otvechat». Латиницу делает сам бот
  (ровно, без ошибок модели); голосом звучит обычная кириллица — транслит синтезатор не прочтёт;
  обратно — `!транслит privet kak dela` → «привет как дела» (или ответом `!транслит` на чужое сообщение,
  словами — «@BazarčikPM переведи с транслита: …»): русские и украинские слова латиницей бот переписывает
  кириллицей через ИИ, английские и словацкие слова, ники и ссылки не трогает. Транслит в просьбах к боту
  («zapomni chto on podkidysh») разбор понимает как обычный текст, а прозвище из транслита сохраняет кириллицей;
- 🤪 **Режим Юрчика** — в манере Юрчика: суржик, «типу», «бро», опечатки. Дообучать модели Groq нельзя, поэтому
  манеру задают его сообщения из `styles/yurchik.txt` — до 40 случайных примеров уходят в каждый запрос.
  Датасет пополняется дописыванием сообщений в файл (через пустую строку), перезапуск не нужен. В файл —
  только манера: без личных данных и опасных тем.

`!режим` — свой режим и кнопки; `!режим юрчик` / `админ` / `стандарт` — сменить свой. Администраторы:
`!режим @user юрчик`, `!режим @user`, `!режим list`. Словами: «@BazarčikPM отвечай мне как юрчик»,
«включи Пете язык админов», «верни мне обычный режим».

## Мини-игры

`!игры` — меню всех игр кнопками; ставку и выбор (орёл/решка, число, цвет) бот спрашивает кнопками, поэтому
команды можно писать без аргументов: `!spin`, `!flip`, `!bj`. Старый вид `!roulette 500 red` тоже работает.
После игры — «🔁 Ещё раз», «⏫ ×2», «⏬ ½» и «🎮 Игры».

`!дурак` — карточная игра с друзьями или ботом. В наборе хозяин стола выбирает в меню: подкидной или переводной,
кто подкидывает (соседи или все), колоду (24 — от девятки, 36, 52) и ставку; остальные жмут «Вступить», «➕ Бот»
добавляет бота. На столе «🃏 Мои карты» открывает руку и меню ходов, видимое только тебе, — в нём лишь
разрешённые ходы, и оно обновляется само. Опции можно сказать словами: `!дурак переводной все 52 бот 500 сразу`,
«Базарчик, давай в дурака с ботом». Ставку вносит каждый, за ботов — банк; дурак теряет ставку, остальные
делят банк (налог как в казино). Не ходишь 2 минуты — за тебя играет бот, пока не нажмёшь любую кнопку.
Правила игры — `durak_engine.py`, кнопки — `cogs/durak.py`.

## Логи

Строки бота в консоли хостинга помечены по модулям: `[listen]` — путь каждой фразы из войса под номером
`#N` и итоги раз в минуту (с памятью и CPU), `[wake]` — детектор «Базарчик», `[jarvis]` — голосовые команды
и подтверждения, `[tts]` — озвучка, `[ai]` — ключи Groq. Текст фраз в логи не пишется. Подробно — `CHANGES.md`, раздел 12.

## Права роли бота

Для модерации роль бота должна стоять **выше** ролей участников и иметь права:
«Модерировать участников» (тайм-ауты), «Банить», «Выгонять», «Управлять сообщениями»,
«Управлять каналами», «Управлять ролями», «Управлять никнеймами».

## Структура

```
main.py          точка входа: создаёт бота, грузит cogs, обрабатывает ошибки
config.py        настройки из окружения
ai.py            ИИ (Groq): ротация ключей, автопереключение моделей
wake_word.py     офлайн-детектор обращения «Базарчик» для прослушивания войса (Vosk)
durak_engine.py  правила «Дурака» без Discord: колода, ходы, добор, бот-игрок
whatsnew.py      «чему новому ты научился»: новые коммиты или разделы CHANGES.md
reply_modes.py   режимы ответа ИИ: стандартный, язык админов (транслит), режим Юрчика (styles/yurchik.txt)
data.py          хранилище JSON (атомарная запись, защита от битых файлов)
utils.py         сроки (10m, 2h, 7d), журнал модерации и лог-канал
cogs/            модули: economy, shop, games (казино, !игры), durak, work, mcdonalds, business, loans,
                 moderation, admin, info, fun, petitions, voice_ai, voice_listen,
                 jarvis (голосовые команды), xp, spt_status; mafia — отключена
```

Код модуля можно перезагрузить без рестарта: `!reload mcdonalds` (владелец бота).
