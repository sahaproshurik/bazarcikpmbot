# BAZARCIK_PM — Discord-бот

Экономика, работа (склад GymBeam и McDonald's), мини-игры (казино и «Дурак»), бизнесы, кредиты, ИИ-ассистент
и инструменты модерации. Префикс команд — `!`, полный список — `!help`, админам — `!adminhelp`.

## Запуск

Нужен Python 3.10–3.14 и FFmpeg (для голоса).

```bash
pip install -r requirements.txt
python main.py
```

На хостинге запуск задан в `Procfile`: `worker: python main.py`.

## Переменные окружения (`.env` или настройки хостинга)

| Переменная | Обязательна | Что это |
|---|---|---|
| `DISCORD_BOT_TOKEN` | да | Токен бота |
| `GROQ_API_KEYS` | для ИИ | Ключи Groq через запятую (старое имя `GROQ_API_KEY` тоже работает) |
| `GROQ_MODEL` | нет | Модель Groq; по умолчанию `openai/gpt-oss-120b`, при отключении модели бот сам перейдёт на следующую |
| `AI_SYSTEM_PROMPT` | нет | Характер ИИ. Встроенный (`config.py`) — BazarčikPM Bot: зеркалит тон, защищает Юру, знает команды бота. Переменная полностью его заменяет |
| `TTS_VOICE` | нет | Голос озвучки, по умолчанию `ru-RU-SvetlanaNeural` |
| `LOCAL_WAKE` | нет | `0` — выключить локальный детектор «Базарчик» (тогда каждую фразу из войса распознаёт Whisper) |
| `SPT_STATUS_GIST_ID` | нет | Gist со статусом SPT-сервера (старая `SPT_STATUS_GIST_URL` тоже понимается) |
| `SPT_STATUS_GIST_FILENAME`, `SPT_STATUS_GITHUB_TOKEN` | нет | Имя файла в gist и токен для частых проверок |

## Голосовой ассистент («Джарвис»)

В чате к боту обращаются **только упоминанием**: `@BazarčikPM сколько у меня денег`,
`@BazarčikPM зайди к нам в войс`. Бот сам решает: выполнить команду или ответить на вопрос как ИИ.
Команды `!ask` больше нет.

**Прозвища** (`!alias`, `cogs/aliases.py` + `names.py`, хранятся в `user_aliases.json` по ID участника):
по ним бот понимает, о ком речь — «@BazarčikPM замуть Петруху». Администраторы меняют прозвища любого
участника сразу; остальные — только свои и только с одобрения администратора (бот присылает запрос с кнопками).
Свои прозвища смотрит любой (`!alias`), чужие и весь список (`!alias @user`, `!alias list`) — администраторы.
Всё это можно и словами: «@BazarčikPM запомни, что Петруха — это Петя», «какие у меня прозвища».

`!listen` — бот слушает войс и отвечает на фразы, которые начинаются с «Базарчик, …»; запасной путь —
голосовое сообщение «Базарчик, …» в чате. Если в фразе просьба что-то сделать, бот сам выполняет свою
команду от имени говорящего, коротко говорит итог голосом и дублирует его в чат:
«Базарчик, сколько у меня денег» → `!money`, «Базарчик, замуть Петю на 10 минут» → `!mute`.
Просто вопрос — обычный ответ ИИ. Список голосовых действий — `!jarvis`.

- Голосом выполняется только белый список (`ACTIONS` в `cogs/jarvis.py`), права проверяются так же,
  как у текстовой команды.
- Мут, варн, медленный режим, замок чата — сразу. Кик, бан, очистка чата — строгое подтверждение: бот
  договаривает вопрос, создаёт форму в чате и 30 секунд ждёт полную фразу вроде «подтверждаю, забань Petya»
  (или кнопку). Переводы и крупные ставки — после «да» (15 секунд).
- Команды модерации понимают ник, прозвище, падеж и транслит: `!mute Петруха 10m`, `!clear от Петрухи за 2ч`.
- `!reload`, `!backup`, `!botstatus` и настройки сервера голосом не выполняются никогда.
- Звук живёт только в памяти до распознавания, фразы без обращения к боту не сохраняются.
- Обращение «Базарчик» в войсе сначала слышит офлайн-детектор прямо на сервере бота (`wake_word.py`, Vosk),
  и в Groq Whisper уходят только фразы с обращением. Модель (~45 МБ) скачивается сама при первом
  `!listen`, на диске занимает ~56 МиБ, в памяти ~90 МиБ — и только пока бот слушает войс.

## Мини-игры

`!игры` — меню всех игр кнопками; ставку и выбор (орёл/решка, число, цвет) бот спрашивает кнопками, поэтому
команды можно писать без аргументов: `!spin`, `!flip`, `!bj`. Старый вид `!roulette 500 red` тоже работает.
После игры — «🔁 Ещё раз», «⏫ ×2», «⏬ ½» и «🎮 Игры».

`!дурак` — карточная игра с друзьями или ботом. В наборе хозяин стола выбирает в меню: подкидной или переводной,
кто подкидывает (соседи или все), колоду (24 — от девятки, 36, 52) и ставку; остальные жмут «Вступить», «➕ Бот»
добавляет бота. На столе «🃏 Мои карты» открывает руку и меню ходов, видимое только тебе, — в нём лишь
разрешённые ходы, и оно обновляется само. Опции можно сказать словами: `!дурак переводной все 52 бот 500 сразу`,
«Базарчик, давай в дурака с ботом». Ставку вносит каждый, за ботов — банк; дурак теряет ставку, остальные
делят банк (налог как в казино). Не ходишь 2 минуты — за тебя играет бот, пока не нажмёшь любую кнопку.
Правила игры — `durak_engine.py`, кнопки — `cogs/durak.py`.

## Логи

Строки бота в консоли хостинга помечены по модулям: `[listen]` — путь каждой фразы из войса под номером
`#N` и итоги раз в минуту (с памятью и CPU), `[wake]` — детектор «Базарчик», `[jarvis]` — голосовые команды
и подтверждения, `[tts]` — озвучка, `[ai]` — ключи Groq. Текст фраз в логи не пишется. Подробно — `CHANGES.md`, раздел 12.

## Права роли бота

Для модерации роль бота должна стоять **выше** ролей участников и иметь права:
«Модерировать участников» (тайм-ауты), «Банить», «Выгонять», «Управлять сообщениями»,
«Управлять каналами», «Управлять ролями», «Управлять никнеймами».

## Структура

```
main.py          точка входа: создаёт бота, грузит cogs, обрабатывает ошибки
config.py        настройки из окружения
ai.py            ИИ (Groq): ротация ключей, автопереключение моделей
wake_word.py     офлайн-детектор обращения «Базарчик» для прослушивания войса (Vosk)
durak_engine.py  правила «Дурака» без Discord: колода, ходы, добор, бот-игрок
data.py          хранилище JSON (атомарная запись, защита от битых файлов)
utils.py         сроки (10m, 2h, 7d), журнал модерации и лог-канал
cogs/            модули: economy, shop, games (казино, !игры), durak, work, mcdonalds, business, loans,
                 moderation, admin, info, fun, petitions, voice_ai, voice_listen,
                 jarvis (голосовые команды), xp, spt_status; mafia — отключена
```

Код модуля можно перезагрузить без рестарта: `!reload mcdonalds` (владелец бота).
